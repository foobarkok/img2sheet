# img2sheet

## 概要
img2sheet は学校の課題のために作成した、画像のそれぞれのピクセルをセルに変換してGoogle Spreadsheetsに書き込むための専用ツールです。既存ですでにありそうですが自作してみました。AIはGeminiとGithub Copilotを使っています。

## 仕組み
Google Apps Script (以下gas) というものがあり、これを使ってGoogle SpreadsheetsやGoogle Drive、その他いろいろなGoogleのサービスをプログラムから操作することができます。これを使います。Pythonのコードで画像を読み込んで文字列に変換し、zstandardで圧縮してテキストファイルに書き込んだものをGoogle Driveにuploadし、これをgasから読み込んでspreadsheetに書き込むことで実現します。

## 使い方
### 概要
1. 画像を用意
2. 変換プログラムをダウンロード
3. 変換プログラムで画像をテキストファイルに変換
4. Google Driveに適切な形でupload
5. gasのプログラムが事前に入ったspreadsheetのテンプレートをコピーする。
6. そのコピー上でプログラムを実行 (これで完了)

### 画像を用意
好きな画像を何でもいいので用意してください。特に思い浮かばないけど試したい場合はいらすとやとかで良いと思います(雑)
厳密には、拡張子はpng/jpg/jpeg/webpあるいはそれの大文字である必要があります。

### 変換プログラムをダウンロード
Windowsの方は`win.exe`、Linuxの方は`linux.py`をダウンロードしてください。自分はApple製品を持ってないのでMacは知りません。多分Linuxとほぼ同様の方法でいけると思います。

### 変換プログラムで画像をテキストファイルに変換
#### Windowsの場合：
変換したい画像と変換プログラムを同じフォルダー内に入れて、そのファイル内に入っている画像ファイルが一つだけになるようにしてください。その状態で`win.exe`をダブルクリックして実行すると黒いウィンドウが出るのでそれが消えるまで放置すればフォルダー内に`a.txt`という名前のテキストファイルが出現しているはずです。

(ちなみに、上記の条件が満たされていない場合は画像のファイル名を入力する入力待ち画面が出てきます。プログラムを停止したい場合はCtrl+Cでできます。具体的なことはプログラムを見ればわかると思います。)

#### Linuxの場合：
Linuxなんて使ってるんですからpipの使い方もわかりますよね? \
opencv-pythonとzstandardパッケージをpip3 installしてからlinux.pyをpython3コマンドで普通に実行してください。後はWindowsの場合と同様です。

### Google Driveに適切な形でupload
Google Driveのマイドライブ内に `mZXjn09dp2zurWN49atK` という名前のフォルダーを作成し、その中にさっき生成されたa.txtを(名前は変更せずに)入れてください。このフォルダー名は元からあるフォルダー名と絶対にかぶらないようにランダムで決めたので特に意味はないです。

### gasのプログラムが事前に入ったspreadsheetのテンプレートをコピーする。
(気持ち的にgoogle accountを大々的に公開したくないので)ここにはテンプレートを貼りません。ほしい方は私に言ってください。
そのシートを自分用にコピーしてくれれば良いです。

### そのコピー上でプログラムを実行 (これで完了)
シートを開いて上のメニューの拡張機能のボタンを押して、そのいくつか下に出てくるApps Scriptというボタンを押してください。左の方に`直接書き込み.gs`と`条件付き書式.gs`の二つの項目が見えると思います。違いを説明します。

直接書き込み→セルごとに色を塗る。高速なので大きな画像向き。\
条件付き書式→セルに入力された数によってセルの色を自動で変える条件付き書式というGoogle Spreadsheetsの機能を使う。これは授業で指定された方法なので厳密にはこれが正規の方法。

とりあえず違いが理解できれば好きな方をクリックして選択してください。わからなければ直接書き込みで良いと思います。

その後に実行ボタンを押すと無事にプログラムが動き始めます。spreadsheetやdrive、外部プログラムのダウンロードなどのために権限の承認を要求してくることがあるのでその場合は~~とりあえず全部承認してください~~ちゃんと読んだ上で承認してください。

### 完了！
とりあえず実行が終わるとシートにはドット絵があるはずです。
